# Text-to-SQL：让业务同学用中文查数据

## 链路拆解
一条自然语言查询要变成可执行 SQL，中间需要几步：先确定要查哪些表（模式链接），再确定连接条件与聚合方式，然后生成 SQL，最后执行并把结果转成自然语言结论。把这几步显式拆开，比让模型一次性吐出 SQL 稳定得多。

## 为什么必须给表结构
模型不知道你的字段名和枚举值，如果不在提示里给出建表语句和若干个取值样例，它只能靠猜，字段名编造是最常见的失败模式。做法是把相关表的 DDL 拼进提示，必要时再附上几行样本数据。

## 评测与护栏
评测用执行准确率：跑生成的 SQL 和标准 SQL，比对结果集是否一致，比比对 SQL 字符串更公平，因为同一语义有多种写法。护栏同样重要，执行前必须校验只允许只读语句，禁止删改语句进入执行环节，并加上行数上限防止拖垮数据库。
