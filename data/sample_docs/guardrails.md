# 安全护栏：别让 Agent 捅娄子

## 最小权限原则
给智能体的工具权限应当按最小够用来配置。文件读写限定在指定目录并对路径做净化，禁止相对路径穿越；数据库只允许只读账号和只读语句；涉及外部写入的操作要人工确认或走二次校验。

## 输入侧与输出侧都要拦
危险不只来自用户输入，也来自模型输出。模型可能生成一条删除语句用于"清理旧数据"。因此解析出意图后先在代码层截住，而不是指望提示词约束住它。提示词提高成功率，代码负责保底线，这条原则在智能体场景尤其重要。

## 成本控制
护栏还包括成本护栏：限制单次运行的步数与 token、对重复失败做熔断、对工具结果做截断再进上下文，避免一条长结果把上下文塞满导致后续轮次全部失效。把这些限制写成可配置的常量，方便在不同场景下拉紧或放松。
